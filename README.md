## 🚀 Featured Projects
 
### [UrbanFlow Valencia — Forecasting & Resource Optimization](https://github.com/luistrge/urbanflow-valencia-mlops)
Team project · Urban-planning decision-support tool for Valencia. 24 CatBoost models forecast hourly traffic across **1,158 zones**; an Integer Linear Programming optimizer uses those forecasts to site infrastructure under real budget constraints. Full MLOps cycle — FastAPI, Docker, CI/CD, drift monitoring.
 
**R² = 0.92** on unseen data &nbsp;·&nbsp; Graded **10/10** &nbsp;·&nbsp; `Python` `Operations Research` `MLOps`
 
### [EXIST 2026 — Multimodal Sexism Detection](https://github.com/luistrge/exist-2026-multimodal-sexism)
Serrano Team's submission to the EXIST 2026 shared task. A hierarchical system combining OCR text, meme images, multilingual language models and physiological signals to detect and characterize sexism in memes, with an audited and reproducible evaluation pipeline.
 
**0.709 macro-F1** (development) &nbsp;·&nbsp; **Top 10–15 of 100+ official runs** across the three subtasks &nbsp;·&nbsp; `Python` `NLP` `Multimodal ML`
